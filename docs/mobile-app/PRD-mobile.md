## 1. 产品目标

**一句话定位**：把 OpenSchedule 的「计划—执行—复盘」闭环装进口袋，让 5–50 人小团队成员**离开工位时也能接任务、记工时、看进度**。

| 编号 | 目标（可衡量） | 衡量指标 |
| --- | --- | --- |
| G1 | 碎片场景可完成「接任务」闭环 | 冷启动 → 成功承接任务 ≤ 15s；承接操作成功率 ≥ 95% |
| G2 | 碎片时间可随手记工时 | 开始/结束计时 ≤ 3 次点击；有任务日工时补录覆盖率 ≥ 60% |
| G3 | 移动端体验达标 | 核心 7 页首屏可交互 ≤ 2s；崩溃率（crash-free sessions）≥ 99.5% |

## 2. 移动端 vs Web 端差异

| 能力域 | Web 端现状 | 移动端策略 | 说明 |
| --- | --- | --- | --- |
| 登录 | 账号密码 / SSO | **强化**：密码登录 + 生物识别解锁（FaceID/指纹）+ 会话持久化 | 高频入口，必须 1 步进 |
| 协作工作台 | 多模块聚合、信息密度高 | **收敛**：只保留「我的待办 + 动态 + 快捷入口」 | 移动端做摘要，不做全量 |
| 今日聚焦 | 有 | **强化**：升级为 Tab 一级入口，支持下拉刷新与右滑快操作 | 移动端主场景 |
| 项目看板 | 列表 + 看板 + 甘特 + 依赖图 | **收敛**：仅保留看板列视图（横向滚动），去掉甘特/依赖图 | 复杂图形不迁移 |
| 任务详情 | 全字段 + 评论 + 附件 + 依赖 | **保留 + 收敛**：保留状态流转/评论/计时/附件；依赖编辑收进二级抽屉 | 核心 |
| 任务执行 | 有 | **合并**：执行面板并入任务详情底部操作区 | 减少层级 |
| 时间容器 | 日/周/月/年 + 热力图 | **收敛**：首版仅日/周视图，08:00–20:00 时间轴 | 年/月视图不做 |
| 审核中心 | 有 | **收敛**：不做独立页，审核动作下沉到「今日聚焦」待办卡与通知 | 首版不设 |
| AI 拆解 / 智能评估 | 有 | **收敛**：只做「查看 AI 提议 + 一键确认/驳回」 | AI 生成入口不在移动端 |
| AI 规则 / 自动化 / Wiki / 数据中枢 / 系统设置 / 人员管理 | 有 | **不做**（移出首版） | 复杂配置留给 Web |
| 我的 | 个人资料 | **强化**：角色切换 + 通知 + 偏好设置 + 退出 | 演示需要角色切换 |
| 审计留痕 | 全量写操作落库 | **保留**：移动端所有写操作同样落 `audit_logs`，无需前端感知 | 铁律，不可省 |

**收敛原则**：移动端优先「**看与快操作**」（查看、承接、流转、计时、评论），弱化「**复杂配置**」（规则、模板、权限、报表搭建）。

## 4. 需求池

### P0（Must have — 覆盖 7 页核心能力）

| 编号 | 需求描述 | 验收要点 |
| --- | --- | --- |
| M-P0-01 | **登录**：账号密码登录，支持「记住我」与会话持久化；token 过期自动静默刷新 | 登录成功进入工作台；错误凭证给出明确文案；杀进程后重开保持登录 |
| M-P0-02 | **登录**：支持生物识别快捷解锁（FaceID/指纹），失败可回落密码 | 首次登录后可开启；解锁失败 3 次回落密码 |
| M-P0-03 | **工作台**：顶部展示当前用户/团队与角色切换入口；展示「我的待办」摘要（最多 5 条） | 数据来自 `tasks`（assignee=我, status≠done）；点击卡片跳任务详情 |
| M-P0-04 | **工作台**：团队动态流（指派/完成/审核/评论事件，倒序分页） | 分页加载；下拉刷新；点击项跳对应任务 |
| M-P0-05 | **今日聚焦**：聚合今日到期任务、待我审核提报、临期预警三类分组 | 三类分组正确归类；数量与后端一致 |
| M-P0-06 | **今日聚焦**：卡片右滑快捷操作（承接 / 开始 / 完成 / 通过 / 驳回） | 右滑露出操作；操作后乐观更新并可撤销 |
| M-P0-07 | **项目看板**：项目列表 + 进入项目后看板列视图（按 `status` 分列，横向滚动） | 列与任务卡片正确渲染；卡片显示标题/负责人/优先级/截止 |
| M-P0-08 | **项目看板**：卡片状态流转（长按拖拽或卡片菜单切换状态） | 变更调用 `PATCH` 并带 `version` 乐观锁；409 冲突给出刷新提示 |
| M-P0-09 | **任务详情**：展示标题/描述/负责人/优先级/起止时间/预估与实际工时/标签 | 字段完整；空字段优雅隐藏 |
| M-P0-10 | **任务详情**：状态机操作（承接→开始→完成提报 / 转移），写操作落审计 | 仅合法迁移可点；非法态置灰；操作后状态与 `audit_logs` 一致 |
| M-P0-11 | **任务详情**：计时器（开始/暂停/结束），累计写入 `time_entries` | 计时中退出重进保持计时；结束写 `duration_seconds` 并回填 `actual_hours` |
| M-P0-12 | **任务详情**：评论区（列表 + 发送 + @提及）与附件上传/预览 | 发送后即时上屏；@提及触发通知；附件 ≤20MB 且类型白名单校验 |
| M-P0-13 | **时间容器**：日/周视图，08:00–20:00 时间轴，展示任务块与个人任务块 | 时间轴正确；块与 `start_at`/`due_at` 对齐；按用户时区渲染 |
| M-P0-14 | **时间容器**：识别并高亮空闲时段；已完成任务灰显 + 删除线 | 空闲段计算正确；完成态样式符合规范 |
| M-P0-15 | **我的**：个人信息、角色切换（manager/member 演示）、通知偏好、退出登录 | 切换后全局视图随之变化；偏好写入 `notification_preferences` |

## 5. 信息架构与导航

### 5.1 Tab Bar 结构（5 Tab）

```
Root
├── AuthStack（未登录）
│   └── LoginScreen                      ← ① 登录
│
└── MainTabs（已登录）
    ├── Tab1 工作台  WorkspaceStack
    │   ├── WorkspaceScreen              ← ② 工作台
    │   ├── NotificationsScreen          （P1 通知列表）
    │   └── TaskDetailScreen             ← ⑤ 任务详情（push）
    │
    ├── Tab2 今日聚焦  TodayStack
    │   ├── TodayFocusScreen             ← ③ 今日聚焦
    │   ├── TaskDetailScreen             ← ⑤ 任务详情（push）
    │   └── AiProposalSheet              （P1 AI 提议确认，底部抽屉）
    │
    ├── Tab3 项目  ProjectStack
    │   ├── ProjectListScreen            ← ④ 项目看板（项目列表）
    │   ├── BoardScreen                  ← ④ 项目看板（看板列视图）
    │   └── TaskDetailScreen             ← ⑤ 任务详情（push）
    │
    ├── Tab4 时间  TimeStack
    │   ├── CalendarScreen               ← ⑥ 时间容器（日/周）
    │   └── TaskDetailScreen             ← ⑤ 任务详情（push）
    │
    └── Tab5 我的  MeStack
        ├── ProfileScreen                ← ⑦ 我的
        ├── NotificationSettingsScreen   （P1 通知偏好）
        └── AboutScreen
```

### 5.2 7 个页面的落位

| 页面 | 落位 | 入口 |
| --- | --- | --- |
| ① 登录 | AuthStack 根 | App 冷启动（无有效会话） |
| ② 工作台 | Tab1 根 | 登录成功 / Tab 切换 |
| ③ 今日聚焦 | Tab2 根 | Tab 切换 |
| ④ 项目看板 | Tab3 根（列表）→ 二级（看板） | Tab 切换 → 点项目 |
| ⑤ 任务详情 | 全局共享 Stack 页 | 从 Tab1/2/3/4 卡片或通知深链 push |
| ⑥ 时间容器 | Tab4 根 | Tab 切换 |
| ⑦ 我的 | Tab5 根 | Tab 切换 |

**导航原则**：任务详情为跨 Tab 共享页；Tab 切换保留各自栈状态；深链统一指向 `TaskDetailScreen`。

| 页面 | 依赖实体 | 关键字段 | Mock 可覆盖 |

| ① 登录 | `User` | `email`, `displayName`, `avatarUrl`, `locale`, `timezone`, `status` | 是（本地 mock token） |

| ③ 今日聚焦 | `Task`, `AiProposal`, `TimeEntry` | Task: `dueAt/status/reviewRequired/submissionStatus/reviewerIds`；AiProposal: `type/status/payload/diffSummary/expiresAt` | 是（AI 提议建议 mock） |

| ⑤ 任务详情 | `Task`, `TaskComment`, `Attachment`, `TimeEntry`, `TaskDependency`, `User` | Task: 全字段（含 `estimatedHours/actualHours/version/tags/source/submissionStatus`）；TaskComment: `content/mentions/parentId/isDecision`；Attachment: `resourceType/resourceId/fileName/size`；TimeEntry: `startedAt/endedAt/durationSeconds/note`；TaskDependency: `prevTaskId/nextTaskId/type/lagDays` | 部分（写操作必须真后端） |

| ⑦ 我的 | `User`, `MemberProfile`, `NotificationPreference`, `UserRole`, `Role` | User: `displayName/email/timezone/locale`；MemberProfile: `skillTags/complexityTier`；NotificationPreference: `eventType/channels/quietHours` | 是（角色切换需 mock） |

**契约通用约定**

| 项 | 约定 |
| --- | --- |
| 时间 | 后端 UTC 存储，前端按 `user.timezone` 渲染 |
| 多租户 | 所有请求携带 tenant 上下文；移动端不感知 `tenantId` 传参细节 |
| 乐观锁 | 任务状态/排序变更必带 `version`，冲突返回 409，前端刷新并提示 |
| 写操作 | 一律经 API，落 `audit_logs`；移动端不做本地写库 |
| Mock 边界 | **读接口可 mock**；**写接口（承接/流转/计时/评论/审核/偏好）必须接真后端** |
