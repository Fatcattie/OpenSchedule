# 协作工作台功能说明

## 已落地的第一版

### 1. 管理权限分级

工作台顶部提供演示角色切换：

- 管理人员：发布战略/计划任务、选择负责人、进入 AI 拆解入口、查看指派与承接。
- 普通人员：浏览待承接任务、承接任务、提交新的任务提报，个人计划通过日历安排。

当前前端使用 mock 数据演示角色视图。真实后端已有 tenant.owner/admin/member RBAC 基础，后续接入时应将角色切换替换为 `/auth/me` 返回的权限点。

### 2. 时间日历看板

默认工作台首页就是时间日历，可切换：

- 日：08:00-20:00 时间轴，可查看任务并识别空闲时段。
- 周：按天查看任务。
- 月：按日期查看任务。
- 年：按月份查看任务。

已完成任务自动灰显并增加删除线；管理人员和普通人员都能从日历进入任务协作。

### 3. MetaSkill 内嵌

MetaSkill 页签可以填写工具名称、用途、输入和执行步骤，保存为当前会话中的工具草稿，为后续接入 Skill 执行器保留结构化入口。

### 4. 完成任务生成 SOP

在日历已完成任务上点击“记录经验”，提交复盘内容后会同时生成：

- 一份 SOP 文档，包含复盘步骤和引用次数。
- 一张 Wiki 经验卡。
- 一条经验记录。

### 5. Wiki 知识库

Wiki 页签支持按标题、摘要和关键词搜索，并显示知识卡来源。经验生成的 Wiki 卡会自动进入列表。

### 6. 经验记录融入 SOP

经验记录包含任务、作者、内容和关键词。保存后内容会作为 SOP 的复用步骤，并用于 Wiki 关键词关联。

### 7. 番茄钟式提醒

番茄钟页签支持选择任务、25 分钟计时、开始/暂停/重置，并展示短休息、长休息和任务实际工时关联规则。

## 运行方式

```bash
cd apps/web
pnpm run typecheck
pnpm run build
pnpm run preview
```

生产构建目录为 `apps/web/dist-mvp-3`，预览地址为 `http://127.0.0.1:4173/`。

## 下一阶段接入建议

当前版本把业务闭环做成了可操作的前端 mock。接真实后端时，优先新增以下持久化实体和端点：

- `task_proposals`：普通成员提报、审核、转任务。
- `calendar_plans`：任务的计划时段、视图范围、手动调整记录。
- `task_experiences`：完成任务后的经验、关键词和作者。
- `sop_documents` / `sop_references`：SOP 版本和来源任务/经验关联。
- `wiki_articles` / `wiki_keywords`：知识卡和关键词倒排关系。
- `pomodoro_sessions` / `reminders`：番茄钟会话、暂停、完成和提醒事件。
- `skill_drafts` / `skill_runs`：MetaSkill 草稿、审核和执行记录。
